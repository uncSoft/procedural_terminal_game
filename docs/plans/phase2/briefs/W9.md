# W9-narration-split: A5 text side: the narrator tells what happened and stops listing what the screen already shows.

Read RULES.md and DECISIONS.md (same folder as this brief) first. The owner's decisions override the plan's approach wherever they differ.

## Approach (from the fix plan)
- Arrival, descend and opening events carry a short arrival line plus what changed. room_facts survives only as RoomView for the interpreter.
- NARRATOR_SYSTEM: don't list the things, people or exits the screen shows; mention one only when something happens to it.
- Drop the 'how you described it last time' replay. room.description becomes a static blurb.
- plain() strips damage, counts, dice and defense, and also runs on RECENTLY. fate_spent and level become mechanic lines.
- Offline narration uses short templates per event kind.
- Drop facts say 'falls to the floor (not picked up)'.
- Guard: add a possession rule, treat the current monster's names as known, and never cut a defeat or pacify sentence.
- Shop facts: keeper name and description only.
- Take boss placement out of the archetype blurbs.
- Highlight a monster only when it is present or seen, never inside place names.
- The draft becomes a lasting 'cracked wall' ref.
- Ship together with W11.

### narration-vs-display
NARRATION VS DISPLAY: how it works today (v2 @404431d). Log entry numbers (#N) are 0-based entries of llm-copy.log, split on its "--- HH:MM:SS kind" headers by /private/tmp/claude-501/-Users-johnt-Developer-procedural-terminal-game/dd9f4e95-dc05-4e1f-9dcb-b8fbbc9ee7a2/scratchpad/audit/narration-vs-display/parse_log.py. The current narrator prompt starts at #1189.

1. FACTS (engine). Actions return Event(kind, text, data). The whole room is turned into ONE English string by rules.room_facts (rules.py:486-525). In order it holds:
   - a secret-room note
   - features with compass positions from layout.where, plus "already used" and "X said something's hidden here" notes
   - the "behind the X wall" tip
   - "On the floor: <items>"
   - either shop_facts (rules.py:818-823: keeper, the meta line "not a monster", the maker's desc, every ware with its price) or FIXTURE_FACTS (rules.py:48)
   - "Exits: " + exit_notes (rules.py:468-483: "unexplored; the stairs down beyond", "where you came from", "locked")
   - the monster line (position, hostile/calm/npc), followed by npcs.facts (npcs.py:180-205, quest state written for the model)
   - tangled
   - "Earlier here: " + room.history (models.py:92,109; written by combat.py:353, creative.py:207, rules.py:589/598/797/973, npcs.py)
   That string goes into five places:
   - the opening arrival Event (game.py:136)
   - every travel "enter" Event, first visits AND revisits (rules.py:451-465)
   - the "descend" Event, together with theme.blurb and "+10 souls" (rules.py:544-569)
   - the narrator's ROOM "Now:" line on turns without an arrival (prompts.py:241-246)
   - the offline answer to a question (narrator.py:34)
   Item facts are separate events:
   - gain_item (rules.py:572-606): take, equip or key, with "(N now)", "(+N defense)" or "(1d8)". An equip appends the old item to room.items and to room.history.
   - "X dropped a Y" (combat)
   - "You search X and find Y" (rules.py:609)
   - collect() auto-takes bombs and keys (rules.py:333)
   A free take or take_all is marked quiet (rules.py:256-259, 326).

2. WHAT THE NARRATOR IS TOLD. Game.finish (game.py:253-298) works like this:
   - It keeps only narratable events (game.py:38).
   - If every event is quiet (take, shop, perk), it prints the event text as it is (game.py:269-271).
   - Authored "exact" story cards get no narration.
   - Anything else goes to narrate() (narrator.py:40-66) with narrator_messages (prompts.py:224-255):
     - SETTING, plus the theme blurb on first visits
     - RECENTLY: the last 6 journal lines, sent raw with "(20/30 HP left)" and the XP tallies
     - THIS TURN (this_turn, prompts.py:208-221)
     - ROOM: the archetype blurb (rooms.toml), plus room_facts unless the turn is an arrival or a question, plus "About the <monster>: <maker desc>"
     - on revisits, "How you described it last time": room.description, set once from the first visit's final text (game.py:141, 282) and never refreshed
     - PLAYER TYPED
     - FACTS: plain(e.text) (prompts.py:190-198), which only turns "(a/b HP left)" into words and strips XP/souls tallies. Questions also get situation() (prompts.py:123-152), which includes HP numbers and PROPS.
   - NARRATOR_SYSTEM (prompts.py:49-68) requires first visits to "mention every listed feature, item, exit direction and monster ... Use the positions given" (lines 60-61). It asks revisits to be brief (line 62) and says dropped or found things stay where they lie (lines 64-65).

3. GUARD (llm/guard.py).
   - Rules.for_turn (63-84) builds "known" from facts, journal, blurbs, and the names of features, items, inventory, monster and history.
   - Gate (122-160) streams sentences and drops these: prompt echo, meta talk, questions or options to the player, a new room called familiar, invented exits, any content monster or item name that isn't known (116-120), and anything past sentence_limit (162).
   - It has no rule for possession (taken vs. still lying) and none for listing items or exits.
   - If nothing survives, or the stream fails, it falls back to offline_narration (narrator.py:63-65).

4. OFFLINE NARRATOR. offline_narration (narrator.py:24-37) joins these pieces:
   - the theme blurb (opening)
   - the archetype blurb (first enter or descend)
   - every narratable event's raw text
   For a question it adds player_status + room_facts word for word. With no events it says "You <raw>. The dungeon is unimpressed."

5. WHAT IS SHOWN. GameScreen._turn (ui/game_screen.py:327-447) runs in this order:
   1. echo "> label" (skipped for card clicks)
   2. create the narration placeholder (_narration_sink, 449-466)
   3. dice lines, HUD, popups, fight animations
   4. fixture moment (588-606), which moves the arrival sprite down the story
   5. on a new floor: a new page, the floor header and the FloorScreen
   6. secret-room and shop banners
   7. the room picture on first visits (_room_card, 755-778). It uses room_picture.draw: perspective from the doorway, with the monster pulled to the middle (room_picture.py:791-797).
   8. the arrival fixture or shopkeeper sprite
   9. loot cards (_loot_moment 608, _show_loot 632, _loot_card 654): full-size item sprites labelled equipped / found / picked up / dropped / left here / on the floor.    10. Game.finish fills the narration, highlighted by widgets.highlight (36) with glossary.build (53), which matches every content monster name.
